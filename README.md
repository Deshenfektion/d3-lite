# d3-lite

A lightweight, D3-inspired visualization engine written from scratch in TypeScript.

This is **not** a drop-in replacement for D3. It is an attempt to rebuild the ideas that sit
underneath modern charting libraries — scales, data joins, scene graphs, coordinate spaces —
in a small enough codebase that all of it can be read in an afternoon.

## Status

Early work in progress. The pipeline is being built bottom-up:

- [ ] Data parsing and transformation
- [ ] Scale system
- [ ] Coordinate system
- [ ] Rendering engine
- [ ] Chart components
- [ ] Interaction layer
- [ ] Reactive state

## Getting started

```bash
npm install
npm test
```
