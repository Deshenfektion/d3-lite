d3-lite examples

Four applications built on the same engine. Each one exercises a different part of the pipeline — parsing, transformation, scales, rendering, interaction and state.

  • Sales dashboard Two sources joined, stacked bars, legend filtering, tooltips.
  • Quality metrics Histogram with live rebinning, scatter plot with quadtree hover.
  • Time-series analytics Brush-to-filter across three linked charts, plus a live feed.
  • Dataset explorer Schema inference driving the encoding choices, paste your own data.
